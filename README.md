# Data Folder

This folder is where the raw dataset lives locally. It is **not tracked in Git** (see `.gitignore`) to keep the repository lightweight.

**File expected here:** `customer_shopping_behavior.csv`

The dataset contains 3,900 rows and 18 columns covering customer demographics, purchase details, and shopping behavior (age, gender, item purchased, category, purchase amount, location, size, color, season, review rating, subscription status, shipping type, discount applied, promo code used, previous purchases, payment method, frequency of purchases).

If you don't have the CSV, search Kaggle for a "Customer Shopping / Consumer Behavior" dataset with matching columns, or use your own retail transactions data with the same schema.
